## Ответы на вопросы
1. **Почему цена из каталога?** Клиент может подменить значение формы. В `services.calculate_cart` стоимость считается как `game.price * quantity`, где `game` взят из базы; `views.add` не читает `request.POST["price"]`.
2. **Неверное количество и удаление; почему корзина сохраняется?** Удаление — отдельная кнопка и адрес `/cart/remove/`; количество 0 отклоняется в `parse_quantity`. Функции `add_item`/`set_quantity`/`remove_item` не меняют старый словарь, а возвращают новый; в `views._apply` корзина в сессию записывается только если ошибки не было.
3. **Какой тест нашёл бы ошибку при объединении строк?** Тест повторного добавления (необязательный): добавить G01 ×1 дважды, ожидать `{"G01": 2}`. Пример:
```python
def test_repeat_add_merges_line(self):
    cart = add_item({}, "G01", "1")
    cart = add_item(cart, "G01", "1")
    self.assertEqual(cart, {"G01": 2})
```

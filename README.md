# Корзина магазина настольных игр (учебный проект)

**Автор:** Оразбай Айтуған Нартайұлы, группа Рпо1-23к, Инновационный Технический колледж, специальность «Разработчик программного обеспечения».

## Цель
Учебный сайт на Django: посетитель выбирает настольные игры, меняет количество и получает проверяемую сумму корзины. Реализованы бизнес-правила корзины, серверная проверка ввода, четыре автотеста и запуск тестов в GitHub Actions.

## Использованные версии
| Компонент | Версия |
|---|---|
| Python | 3.11 |
| Django | 5.2.18 (закреплена в `requirements.txt`) |
| База данных | SQLite (входит в Python) |
| ОС для проверки | Windows 10 / localhost |


## Установка и запуск (Windows, PowerShell)
```powershell
git clone <ссылка-на-репозиторий>
cd boardgames-cart
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_catalog
python manage.py runserver
```
Откройте http://127.0.0.1:8000/ — на одной странице каталог и корзина.

## Каталог и его восстановление
Каталог (вымышленные товары) хранится в SQLite:

| Код | Название | Цена, ₸ | Доступно |
|---|---|---|---|
| G01 | Космический маршрут | 4500 | 3 |
| G02 | Город мастеров | 7200 | 2 |
| G03 | Лесные тропы | 3000 | 0 |

Команда `python manage.py seed_catalog` создаёт или **восстанавливает** эти записи (`update_or_create` по коду), поэтому её можно запускать сколько угодно раз — дубли не появляются.

## Правила корзины
- Количество — целое число от 1 до доступного остатка. Отклоняются 0, −1, 1.5, пустая строка и текст.
- Одна игра — одна строка: повторное добавление увеличивает количество; превышение остатка отклоняется целиком.
- G03 — «Нет в наличии», добавление запрещено; неизвестный код (например G99) — «Товар не найден».
- Стоимость строки = цена × количество; суммы — целые тенге; пустая корзина = 0.
- Цена всегда берётся из каталога на сервере; значение `price` из формы игнорируется.
- Корзина хранится в сессии. При ошибке прежняя корзина не меняется, показывается сообщение.
- Покупка не оформляется, остаток в базе не списывается.

## Тесты
```powershell
python manage.py test
```
Четыре проверки: итог обычной корзины (G01×2 + G02×1 = 16200), пустая корзина (0), превышение остатка (G01×4 при остатке 3), неизвестный товар (G99). В GitHub Actions (`.github/workflows/tests.yml`) запускается та же команда.

## Где что менять (передача проекта)
| Что менять | Где |
|---|---|
| Игры, цены, остатки | `shop/catalog.py`, затем `python manage.py seed_catalog` |
| Бизнес-правила и проверки количества | `shop/services.py` (`parse_quantity`, `validate_quantity`, `add_item`, `set_quantity`, `remove_item`, `calculate_cart`) |
| Обработка запросов и сообщения | `shop/views.py` |
| Страница (каталог + корзина) | `shop/templates/shop/index.html` |
| Автотесты | `shop/tests.py` |

## Ограничения
Нет оплаты, доставки, промокодов, регистрации и нескольких покупателей; корзина живёт в сессии одного локального посетителя; дизайн не предусмотрен; режим `DEBUG` включён (учебный проект, не для продакшена).
